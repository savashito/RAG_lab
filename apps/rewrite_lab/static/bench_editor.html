📝 Editor JSON del set

Cómo se escribe un set

  • "topic" es el id del tema (p. ej. derecho_penal_mexicano): las preguntas se responden buscando sólo en él.
  • Cada pregunta lleva "question" (obligatorio), "expected_answer" (la respuesta de referencia que ve el juez), "notes" (no se mandan al juez; HUECO CORPUS marca huecos del corpus) y "components".
  • "id": no lo cambies. Identifica la pregunta para actualizarla en su lugar y que las corridas sigan siendo comparables. Las preguntas nuevas van sin id; si borras una pregunta del JSON, se borra del set (te lo confirmo antes).
  • "kind" del componente: mustobligatorio shoulddeseable must notno debe aparecer — y "weight" (número ≥ 0, por defecto 1).
  • Si una pregunta no tiene componentes, se califica contra "expected_answer" como un único must.

Plantilla

{
  "question": "¿…?",
  "expected_answer": "Art. … : …",
  "notes": "",
  "components": [
    {"kind": "must", "text": "…", "weight": 2},
    {"kind": "should", "text": "…", "weight": 1},
    {"kind": "must_not", "text": "…", "weight": 1}
  ]
}

Atajos

  • Ctrl/⌘ S guardar · Ctrl/⌘ Shift F formatear
  • Clic en una tarjeta de la vista previa → salta a esa pregunta en el editor; mover el cursor en el editor resalta su tarjeta.
  • Clic en un problema → salta a la línea.
  • ▸ en el margen pliega una pregunta o una lista.
